# MBeacon ESP32-C3 广播学习/重播

合宙 ESP32C3-CORE 简约版上用的。把固件、烧录工具、源码和说明都堆在这个仓库里，省得以后到处找。

不用焊接，上电就默认广播。短按板载 BOOT 键开始扫描学习，D4 快闪；学到完整数据、并且广播真的启动成功了，D4 长亮 3 秒再慢闪。学到的数据存 NVS，下次不用重学。

东西在这：

- 完整包：`release/MBeacon_LuatOS_C3_USB_2026-10-14_v2.zip`，里面有首次烧录镜像、乐鑫烧录工具、源码和图文说明
- 图文说明：`docs/使用说明.html`，下载完整包后双击就能看，第一次烧录跟着图走就行
- Arduino/PlatformIO 工程在 `ESP32_BLE_Clone/`，目标 MAC、引脚、广播间隔都在 `include/config.h` 里改

先说清楚这版的来历：它是针对一个具体地址 `C3:00:00:1B:95:0F` 和一份 MBeacon 广播样本做的，不是通用克隆工具。要是地址类型对不上，没法用相同 MAC 重播，或者广播启动失败，固件会直接报错，不会假装成功亮灯——这点是故意这么写的，免得对着灯瞎猜。

没验证的部分也直说：源码用 `luatos_usb` 和 `luatos_classic` 两种配置都编译通过了，镜像和 ZIP 做过软件校验，但发这个版本的时候我还没拿到实物板子。实机烧录、手机能不能收到、原 App 认不认，都还没测。另外就一份手机扫描记录，其实证明不了目标的真实地址类型、PDU 类型和连接认证行为，拿到板子后还得实测。
