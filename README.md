# MBeacon ESP32-C3 广播学习与重播工具

我把合宙 ESP32C3-CORE 简约版所需的固件、烧录工具、源码和新手操作说明整理在这里。无需焊接，上电默认广播；短按板载 BOOT 键开始扫描学习，D4 快闪；成功收到完整目标数据且启动广播后，D4 长亮 3 秒，然后慢闪。

- [下载完整安装包](release/MBeacon_LuatOS_C3_USB_2026-10-14_v2.zip)：包含首次烧录镜像、乐鑫烧录工具、源码和图文说明。
- [阅读图文说明](docs/使用说明.html)：适用于首次烧录和日常使用。下载完整包后双击其中的 `使用说明.html`，即可在浏览器中按图操作。
- [查看 Arduino/PlatformIO 工程](ESP32_BLE_Clone/)：目标 MAC、引脚和广播间隔在 `include/config.h` 中配置。

本版针对目标地址 `C3:00:00:1B:95:0F` 和提供的 MBeacon 广播样本制作。扫描到新的完整数据后，固件会保存至 NVS；数据未变化时也会给出成功灯号。若地址类型无法使用相同 MAC 重播，或广播启动失败，固件会明确提示，不会显示成功灯号。

源码已通过 `luatos_usb` 与 `luatos_classic` 两种配置编译，合并镜像和 ZIP 经过软件校验。发布时尚未取得实物板，实机烧录、手机接收和原 App 识别仍待验证。单份手机扫描记录也不能证明目标的真实地址类型、空中 PDU 类型或连接认证行为。
